# Syntelab Creative brand

Logo (SVG + PNG), color palette, fonts. To be added, matching syntelab.com.

| File | Contents |
|---|---|
| `icon.svg` | Program logo. Square `viewBox`, one color (the program paints it in the brand color `#007BFF`). After replacing it, run `node tools/generate-icons.mjs` to rebuild the window and taskbar icons. |
| `fonts/sansation/` | Brand font and its license |
