# 0009 — English-only source and documentation

**Context:** The app ships in 62 languages and will be open source. Contributors and translators work from one source language.

**Decision:** All code, comments, documentation, commit messages and source strings are in **English**. Other languages exist only as translations in `locales/` folders. Conversations about the project can be in any language.

**Consequences:** Earlier Romanian documents were translated. Translators always work from English.
