## ✨ Why Syntelab Creative

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>🔒 Private by design</h3>
      <p>Your files never leave your computer. No account, no sign-in, no telemetry. The program goes online only when you ask it to: currency rates, a web page you open, a network check.</p>
    </td>
    <td width="33%" valign="top">
      <h3>♾️ No limits</h3>
      <p>No page counts, no file-size caps, no daily quotas, no paid tiers. A thousand-page PDF or a gigabyte of text: the only limit is your hardware.</p>
    </td>
    <td width="33%" valign="top">
      <h3>🗂️ One window</h3>
      <p>Every app opens in a tab of the same program. One install, one set of settings, light and dark themes for all of them.</p>
    </td>
  </tr>
  <tr>
    <td width="33%" valign="top">
      <h3>🔄 Signed updates</h3>
      <p>New versions download and install themselves. Each update is checked against our signature before it runs.</p>
    </td>
    <td width="33%" valign="top">
      <h3>🌍 62 languages</h3>
      <p>Menus, messages and help, all translated. Full right-to-left (RTL) support: in Arabic, Hebrew, Persian and Urdu the whole interface is mirrored.</p>
    </td>
    <td width="33%" valign="top">
      <h3>📖 Open source</h3>
      <p>The code is public under the AGPL v3.0: anyone can read it, check what it does and build it themselves.</p>
    </td>
  </tr>
</table>

## 🤝 Help the project

Syntelab Creative is open source, and it gets better with every pair of eyes on it. If you like it, here is how you can help:

- 💻 **Read the code and propose changes.** Look at how something is built, find what can be done better, and send a pull request. For a larger change, open an issue first so we can talk about it.
- 🐞 **Report bugs.** [Open an issue](https://github.com/SyntelabHQ/syntelab-creative/issues) with the steps to see it, your system and the version of the program.
- 🌍 **Improve a translation.** The texts are in the `locales/` folders; `en.json` is the source, every other language follows it.
- ❤️ **Support us.** The program is free, and keeping it that way takes time. A donation, one-time or monthly, helps: [syntelab.com/support](https://syntelab.com/support).
- 📣 **Tell others.** A star on this repository or a recommendation to a friend helps more people find it.

By sending a contribution you agree that it is published under the same license, the [GNU AGPL v3.0](LICENSE).

<details open>
<summary><b>Build from source</b></summary>

You need [Node.js](https://nodejs.org/) and [Rust](https://www.rust-lang.org/tools/install), plus the system packages listed in the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/).

```bash
git clone https://github.com/SyntelabHQ/syntelab-creative.git
cd syntelab-creative
npm install
npm run dev      # run the program while you work on it
npm test         # tests
npm run build    # build the installer for your system
```

</details>

## 🧱 Built with

Syntelab Creative stands on the work of many open source projects. Thank you to all of them. The main ones:

| Project | What it does in Syntelab Creative |
|---|---|
| [Tauri](https://tauri.app) | The program window and the bridge between the interface and Rust |
| [MuPDF](https://mupdf.com) | Reading, drawing and writing PDFs in PDF Organizer |
| [React](https://react.dev) | The interface |
| [CodeMirror](https://codemirror.net) | The text editor of SCRIBE and DEV |
| [RustCrypto](https://github.com/RustCrypto) and [rustls](https://github.com/rustls/rustls) | Hashes, keys, certificates and secure connections in DEV |
| [similar](https://github.com/mitsuhiko/similar) | Comparing two texts in SCRIBE and DEV |
| [encoding_rs](https://github.com/hsivonen/encoding_rs) and [chardetng](https://github.com/hsivonen/chardetng) | Reading and writing text in any encoding |
| [jiff](https://github.com/BurntSushi/jiff) | Dates, times and time zones |
| [calamine](https://github.com/tafia/calamine) and [rust_xlsxwriter](https://github.com/jmcnamara/rust_xlsxwriter) | Excel and OpenDocument tables in UNITS |
| [IBM Plex](https://github.com/IBM/plex), [Sansation](https://fonts.google.com/specimen/Sansation) and [Font Awesome Free](https://fontawesome.com) | Fonts and icons |
