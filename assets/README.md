# assets — shared resources

| Folder | Contents |
|---|---|
| `brand/` | Syntelab Creative logo, colors |
| `icons/` | Interface icons (Font Awesome Free), one SVG per icon |
| `fonts/` | Fallback fonts for scripts missing on some systems (see `docs/localization/README.md`, section 5) |

Each app's icon and color live in the app folder (`apps/<app-id>/assets/`).
