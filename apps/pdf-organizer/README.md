# PDF Organizer

First Syntelab Creative app. id: `pdf-organizer` · Engine: **MuPDF**.

Everything that belongs only to PDF Organizer lives in this folder.

| Folder | Contents |
|---|---|
| `PLAN.md` | What the app does and in what order we build it |
| `app.json` | App manifest for the shell |
| `backend/` | Rust: all PDF work (MuPDF) |
| `frontend/` | React: viewer, binder, tools, signing |
| `addons/` | Heavy parts on demand (OCR) |
| `locales/` | App translations (`en.json` is the source) |
| `assets/` | App icon and color |
| `tests/` | App tests |
