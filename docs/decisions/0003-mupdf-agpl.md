# 0003 — MuPDF as PDF engine, AGPL-3.0 license

**Context:** We need fast rendering and complete editing (text, images, annotations, forms).

**Decision:** MuPDF. Because it is AGPL, all of Syntelab Creative is AGPL-3.0 and is published with the first stable release.

**Consequences:** A commercial license only from Artifex (not needed). The name is protected separately, as a trademark.
