# packages — shared TypeScript/React code

| Package | Role |
|---|---|
| `shell-api` | Contract for app interfaces (tabs, commands, settings, jobs) |
| `command-registry` | Command registry: feeds ribbon, menu, panel, search, shortcuts |
| `ui-kit` | Shared components, themes (light/dark/auto), RTL support |
| `data-grid` | The table of rows and cells drawn only where in sight, shared by Units and Dev |
| `text-editor` | The editor texts are written and shown in (CodeMirror), shared by Scribe and Dev |
| `i18n` | Translation loading (global + per app), language detection, LTR/RTL, number/date formatting |
