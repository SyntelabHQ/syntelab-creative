# Metadata

Tools for the hidden data of files: seeing and removing what photos, videos
and documents carry besides what they show (EXIF, GPS, tags, authors).
The model is the online tool at <https://flint.skalda.io/metadata-tools/>.

Status: **coming soon**. Only the manifest (`app.json`) and the icon exist.
A `PLAN.md` is added when work on the app starts
(see `docs/architecture/new-app.md`).
