# 0006 — Name: Syntelab Creative (replaces Skalda)

**Context:** The Skalda name has a trademark conflict.

**Decision:** The project is called **Syntelab Creative**. Website: **syntelab.com**. In code: prefix `syntelab-` (e.g. `syntelab-core`).

**Consequences:** All links (catalog, news, feedback, donations) use syntelab.com. The trademark must be checked on EUIPO/TMview before launch.
