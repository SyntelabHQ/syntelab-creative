# Glossary

Terms that must stay consistent across the shell and all apps.

## Never translated

| Term | Note |
|---|---|
| Syntelab Creative | product name |
| PDF Organizer | app name |
| Convert | app name |
| PDF, OCR, PAdES, LTV | technical terms |

## Translated consistently

| English | Meaning | Note for translators |
|---|---|---|
| app | a part of Syntelab Creative the user can install (PDF Organizer, Convert) | not "plugin" or "module" |
| add-on | an optional heavy part of an app (e.g. OCR) | |
| binder | the view where each file is a card with its pages | |
| merge | join several files into one PDF | |
| split | divide one PDF into several | |
